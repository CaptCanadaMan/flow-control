# Flow Control

Flow Control is a WebMCP-powered control surface for human-supervised autonomy. It gives people and agents a shared live workspace where agents can operate within delegated authority, surface consequential decisions, and continue after explicit human approval.

The hackathon demonstration uses a simulated airspace operations environment to make this interaction model concrete. Dynamic traffic, competing objectives, safety constraints, and time-sensitive conflicts provide a demanding test of coordination between autonomous systems and a human supervisor. The same supervisory pattern could extend to robotics, autonomous fleets, industrial systems, and other consequential operations.

This project is being built for the WebMCP Challenge. Implementation and local development instructions will be added as the application takes shape.
